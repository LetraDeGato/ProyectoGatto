# ProyectoGatto
Proyecto a presentar en el de Curso Desarrollo De Videojuegos Y Entornos Interactivos (3336516) SENA 2025.
## Descripción
Un videojuego épico y juguetón donde un gato protagonista intenta robarle a un dragón. El universo combina humor felino, narrativa simbólica y mecánicas de sigilo, con personajes memorables. El proyecto busca integrar estética visual llamativa, atmósfera narrativa y elementos interactivos que inviten al jugador a explorar y disfrutar de una aventura única.

Motor de desarrollo (tentativa Unity)
